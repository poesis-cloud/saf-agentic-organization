# Release on Demand — commit release

The Product Manager records the business release decision for this increment.

Inputs: the System Demo packet and the Operator operability-review.
Output: the release-on-demand artifact. Hold, dark-launch, canary, or release. Do not rewrite Features, Enablers, or the operability-review. Do not invent a separate Continuous Deployment ceremony.
