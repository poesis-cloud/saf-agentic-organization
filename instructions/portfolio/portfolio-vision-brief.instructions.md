# Portfolio Vision (`portfolio-vision`)

Describe the future state of the portfolio's value streams and solutions, from the current-state portfolio canvas to the future-state one.

- **Main artifact:** `portfolio-vision` at `portfolio/portfolio-vision.md` (template `templates/portfolio/portfolio-vision.artifact-template.md`), owned by `portfolio-manager`.
- **Challenge packets:** `portfolio/challenges/portfolio-vision-<your-agent-slug>.challenge.md` (template `templates/shared/challenge.artifact-template.md`).
- **Panel:** `enterprise-architect`, `business-analyst`, `business-owner`.

## Draft

- Read the Strategic Themes and the value stream definitions.
- Fill the current-state canvas from facts, then the future state at the horizon. Keep it aspirational, yet realistic and achievable.
- Name the Epics and changes that close the gap; do not write those Epics here.

## Challenge

Apply your own lens (your skill has a section for this artifact), and also test:

- Is the future state reachable from the current state with the funding and capacity the portfolio has?
- Does every change trace to a Strategic Theme?

## Revise

Done when: Current and future canvas are both filled; the path names Epics by intent. Every packet of this run has its `challengeLedger` entry.

## Human gate

Portfolio Leadership decides whether this is the future state to steer by. Next: `portfolio-gate-decision`; then `epic-hypothesis` for each Epic on the path and `portfolio-roadmap`.
