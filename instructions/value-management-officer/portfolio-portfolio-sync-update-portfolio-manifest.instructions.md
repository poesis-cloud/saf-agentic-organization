# Portfolio Sync — update Portfolio Manifest

The Value Management Officer refreshes the portfolio ART / product registry after the sync.

Inputs: the Portfolio Sync record, current Strategic Themes, and registered ARTs / products.
Output: the portfolio-manifest artifact. Do not rewrite Themes, Vision, or Epic content.
