# Strategic Portfolio Review — update Architectural Vision

The Enterprise Architect updates the portfolio technology vision so it tracks strategy.

Inputs: Strategic Themes, Portfolio Vision, current Architectural Vision, and Enabler Epics.
Output: the architecture-vision artifact. Do not write business Themes, Vision, or the review decision.
